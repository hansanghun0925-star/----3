# 궁·능 일별 관람객 2015～2025

국가유산청 궁능유적본부가 공공데이터포털에 해마다 올리는 「4대궁 관람객 수 현황」과 「조선왕릉 관람객 수 현황」 연도별 파일 18개를 한 표로 이은 정리본입니다. 궁 4곳·종묘·조선왕릉 18곳, 모두 23개소의 날짜별 관람객 수를 유료·무료, 내국인·외국인 언어권으로 나눠 담았습니다. 개소 좌표, 같은 좌표의 일별 기온·강수, 한국 공휴일 달력을 함께 둡니다.

값은 원자료 그대로입니다. 고치거나 채운 값은 없고, 형식(천 단위 쉼표, 칸 앞뒤 공백, 파일 끝의 빈 행)만 걷어 냈습니다.

### 개소 좌표

국가유산청 국가유산 검색 오픈API 상세(`https://www.khs.go.kr/cha/SearchKindOpenapiDt.do`)의 사적별 `longitude`·`latitude` 와 소재지(`ccbaLcad`)입니다. 조회일 2026-10-10. 개소마다 요청한 식별자는 `sites.csv` 의 `coord_source` 에 있습니다.

### 날씨

NASA POWER 일별 점 API (`https://power.larc.nasa.gov/api/temporal/daily/point`, API v2.10.0, 시간 기준 LST, community RE). 매개변수 `T2M`·`T2M_MAX`·`T2M_MIN`·`PRECTOTCORR`. NASA POWER 가 요청하는 출처 표기는 아래 두 문장입니다.

> The data was obtained from National Aeronautics and Space Administration (NASA) Langley Research Center's Prediction Of Worldwide Energy Resources (POWER) project funded through the NASA Earth Science Division.
>
> The data was obtained from the POWER Project's Daily 2.10.0 version on 2026/10/10.

**정확도.** NASA POWER 는 격자 자료라 23개소의 날씨가 4개 계열뿐이고, 궁 4곳과 종묘를 포함한 18곳이 같은 값을 씁니다. 기상청 서울 관측소(지점 108) 일별 값과 비교하면 기온(`t2m` 대 일평균 기온, 3,876일)의 상관은 0.989 입니다. 강수(`precip_mm`)는 관측 강수가 남아 있는 1,167일에서 상관이 0.445 이고, 관측소에서 1mm 이상 비가 온 날 가운데 이 파일도 1mm 이상인 날은 70.8%, 관측 10mm 이상인 날 243일 가운데 이 파일도 10mm 이상인 날은 56.0% 입니다. 그래서 강수량은 연속값보다 비 온 날 여부(0·1)로 쓰기를 권합니다. 비교에 쓴 관측값은 NOAA GHCN-Daily 의 `KSM00047108`(공개 자료)입니다.

## 알려진 이상

1. **행이 없는 날**: 2020-05-30～2020-07-21 (53일). 궁·왕릉 원본 모두 이 날짜 줄이 없습니다 (22개소). 사유는 원본에 없습니다. 채우지 않았습니다.
2. **휴관일은 0**: 정기 휴관 요일과 임시 휴관일이 0 으로 들어 있습니다. `total` 이 0 인 행은 8,832개입니다. 0 을 수요 0 으로 학습하면 안 됩니다. 개소 × 요일별로 0 인 비율은 `checks/closed_weekday_check.csv` 에 있습니다.
3. **휴관 요일에도 문을 연 날**: 정기 휴관 요일에 해당하는 행 8,847개 가운데 918개는 관람객이 있습니다. 그중 641개는 공휴일이고 277개는 공휴일이 아닙니다. 공휴일이라 문을 연 날의 다음 날이 0 인 경우는 301/641 로, 휴관이 다음 날로 옮겨 가는 해와 그렇지 않은 해가 섞여 있습니다. 이 날들은 요일 평균에 영향을 줍니다. 예를 들어 2023～2025년 경복궁이 문을 연 화요일은 14일(그중 공휴일 9일)뿐인데 평균 22,753명으로, 다른 요일 개방일 평균 19,991명보다 큽니다.
4. **경복궁 화요일의 작은 값**: 2018-06-05～2022-06-07 경복궁의 공휴일 아닌 화요일 185일은 유료 0, 무료만 있는 날입니다(중앙값 116명). 가장 큰 두 날은 2022-05-17 17,016명, 2022-05-10 9,985명입니다. 그 밖의 해에는 경복궁 화요일이 0 입니다. 「0 = 휴관」 규칙만으로는 이 기간의 휴관일을 가려내지 못합니다.

## 만든 방법

`build_heritage.py` 하나로 만듭니다 (python 3.13, pandas 2.3.3, pyarrow 25.0.1, numpy 2.4.2, holidays 0.103).

1. 공공데이터포털 두 데이터의 현재 판과 「주기성 과거 데이터」 판을 내려받습니다 (로그인·키 없음). 판마다 `POST https://www.data.go.kr/tcs/dss/selectFileDataDownload.do` 에 `publicDataPk`, `publicDataDetailPk`(판 식별자), `fileDetailSn=1`, `publicDataTyCode=PR0051` 을 보내 `atchFileId` 를 받고 `https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=…&fileDetailSn=1` 로 받습니다. 받은 파일의 sha256 을 스크립트가 확인합니다.
2. cp949 로 읽고, 열 이름 `{개소}({구분})` 의 마지막 괄호를 구분으로, 그 앞을 개소로 나눕니다. 개소·구분 표기를 대응표로 맞춥니다.
3. 칸의 앞뒤 공백과 천 단위 쉼표를 걷어 내고 정수로 읽습니다. 빈칸은 빈칸으로 둡니다. 모든 칸이 빈 행은 버립니다.
4. 날짜 × 개소 한 행으로 모으고, `total = paid + free` 를 더합니다. (날짜, 개소) 중복 0 을 확인합니다.
5. 개소 좌표는 국가유산 검색 오픈API 상세를, 날씨는 개소 좌표마다 NASA POWER 일별 API 를 한 번씩 부릅니다 (요청 사이 1.5초). 응답 원문은 정리 담당이 보관하고, 다시 만들 때는 저장한 응답을 씁니다.
6. 달력은 `holidays.KR` 로 만들고, 설날·추석 당일은 공휴일 이름이 「설날」·「추석」인 날입니다.
7. parquet 로 쓰고 다시 읽어 검산값을 새로 계산해 처음 값과 같은지 확인합니다.
